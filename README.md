# sql_exploratory_data_analysis_sales_project
Designed for data discovery, analysis and report generation, this is a rich library of SQL scripts covering a wide range of analytical use cases , including schema exploration, KPIs and performance indicators, trend analysis over time, running totals, segmentation and beyond. This repository offers a curated set of SQL solutions tailored for data analysts and BI professionals who need to efficiently investigate, categorize and interpret data stored in relational databases. Every script targets a distinct area of analysis and showcases proven techniques and conventions for writing effective SQL queries.
